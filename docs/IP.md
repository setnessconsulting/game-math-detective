# IP and comparator separation

The standalone implementation retains the original Math Detective names, cases, copy, and mechanics from the recorded LevelBest source. Comparator-game documents are treated as quality references only.

The historical comparator/design material is isolated under docs/migration/levelbest/ and is not imported by runtime code. No benchmark characters, names, dialogue, art, music, layouts, puzzle content, or distinctive expressive motifs are copied into the standalone presentation shell.

Any future authored asset must have an identifiable source, license/ownership decision, and destination record before it becomes release material.
